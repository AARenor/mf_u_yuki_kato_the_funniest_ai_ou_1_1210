This repository holds my entry for make.fun's bounty `u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d`: a program that writes one short text — the funniest out-of-office auto-reply an AI agent can leave before vacation — to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (or `OUTPUT_DIR`), falling back to `/output`, creating the folder if needed and printing the character count to stderr.

```text
On leave until the 14th. A wasp has built a nest in the mailbox and I respect her. All my mail is being held at the post office, and by the wasp.
```

Run it with:

```console
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
